# スプレッドシート版 Obsidian ナレッジベース

メール・Claude セッションを 1 か所のスプレッドシートに集約し、Obsidian のように
リンク・バックリンク・タグで関連付けて、毎日自動更新するための仕組み。

## 全体像

```
毎朝 7:00 JST (Routine が新しい Claude セッションを起動)
  │
  ├─ 1. Google Drive「Claudeナレッジベース」フォルダから最新の kb_data_*.json を取得
  ├─ 2. Gmail から過去24時間のメールを取得
  ├─ 3. claude-code-remote の list_sessions で直近の Claude セッションを取得
  ├─ 4. Claude が要約・タグ付け・既存ノートとの関連付け (リンク) を行い JSON に追記
  ├─ 5. build_kb.py で Excel ブックを生成
  └─ 6. kb_data_YYYY-MM-DD.json と ナレッジベース_YYYY-MM-DD.xlsx を Drive にアップロード
```

- **マスターデータ**: `kb_data_YYYY-MM-DD.json` (Google Drive 内)。日付付きで毎日追加され、
  最新のものが常に全履歴を含む。過去の日付のファイルはスナップショットとして残る (不要なら削除可)。
- **閲覧用**: `ナレッジベース_YYYY-MM-DD.xlsx`。Google Drive 上でダブルクリックすると
  Google スプレッドシートとしてそのまま開け、数式もその場で計算される。

## Obsidian 相当の機能とシートの対応

| Obsidian | スプレッドシート側 |
|---|---|
| ノート | 「ノート」シートの 1 行 (メール / Claude / ハブ / メモ) |
| `[[リンク]]` | 「リンク先」列 + 「リンク」シート (グラフのエッジ一覧、ID クリックでノート行へジャンプ) |
| バックリンク | 「バックリンク」列 (自動導出) + 「被リンク数」列 (COUNTIF 数式) |
| `#タグ` | 「タグ」列 + 「タグ」シート (索引、件数は COUNTIF 数式) |
| MOC (ハブノート) | 種別「ハブ」のノート。新規ノートはまずいずれかのハブに紐付ける |
| グラフビュー | 「リンク」シートがエッジ一覧。ダッシュボードに最多被リンクノートを表示 |

## リポジトリに置くもの / 置かないもの

**このリポジトリはパブリック**なので、個人データ (メールの内容・要約・送信者など) は
一切コミットしない。リポジトリには仕組みだけを置く:

- `build_kb.py` — kb_data.json → Excel ブック変換スクリプト (データは含まない)
- `routine_prompt.md` — 毎日のルーティンが実行する手順書
- 個人データは Google Drive の「Claudeナレッジベース」フォルダのみに保存する

## 手動での使い方

```bash
python3 knowledge-base/build_kb.py kb_data.json kb.xlsx
```

- ノートを手で追加したいときは、Drive 上の最新 `kb_data_*.json` に追記して再生成する
  (スプレッドシート側を直接編集しても、翌日の自動生成で上書きされるため)。
- ID 規約: `M-YYYYMMDD-NN` (メール) / `C-YYYYMMDD-NN` (Claude) / `H-名前` (ハブ) / `N-...` (メモ)。
- タグは既存語彙を優先して再利用する。別タグの部分文字列になる名前は作らない
  (タグ件数を COUNTIF のワイルドカード一致で数えているため)。

## 取り込み範囲と制限

- **メール**: Gmail の全受信メール (過去24時間分を毎日取り込み)。
- **Claude セッション**: Claude Code のセッション一覧 (タイトル・状態・要約)。
  claude.ai の通常チャットの履歴は API から取得できないため対象外。
  残したい会話はセッション化するか、メモノートとして手動追加する。
